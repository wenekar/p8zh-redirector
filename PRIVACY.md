# Privacy policy

p8zh Direct does not collect, store, or transmit personal data, browsing history,
or link contents. It has no analytics, telemetry, accounts, remote code, or
background network requests.

When you open a supported `p8zh.adj.st` link, the extension reads its URL locally
and extracts the `adjust_redirect` destination. It asks Firefox to navigate to
that destination. The destination's query parameters, including any tracking
values already in the link, are preserved.

The destination website receives the normal browser request and handles it under
its own privacy policy. Links the extension cannot resolve continue through
Firefox's normal navigation behavior.

The extension requests access only to `p8zh.adj.st`. It does not request cookie,
history, or storage permissions.

Questions can be raised through
[GitHub Issues](https://github.com/wenekar/p8zh-redirector/issues). Avoid including
personal tracking values in public reports.
